# Aurora / Parsl provenance

`parsl_config.py` contains the shared Parsl executor configuration used for the bulk ChromBPNet tasks run on the Aurora supercomputer at the Argonne Leadership Computing Facility (ALCF).

The model-training and interpretation stages used Intel Data Center GPU Max 1550 accelerators and the system TensorFlow framework available on Aurora. A separate environment/setup script is not included because the original Aurora environment is no longer available for verification.
