# Single-cell CEBPA/SPI1 reprogramming analysis

This directory contains the single-cell analysis code for the CEBPA/SPI1 reprogramming experiments supporting **Figures 7 and 8** and **Supplementary Figures S7 and S8**.

## Included analysis

The analysis is provided as an extracted directory:

```text
CEBPA-SPI1-single-cell-reprogramming/
```

The scientific content of the supplied analysis package has **not been modified**. Scripts, analysis logic, parameters, and the original project README are preserved as provided. Only archive packaging and macOS metadata files (`.DS_Store` and `__MACOSX`) were omitted when integrating it into this repository.

See [`CEBPA-SPI1-single-cell-reprogramming/README.md`](CEBPA-SPI1-single-cell-reprogramming/README.md) for the original analysis instructions and dependencies.
